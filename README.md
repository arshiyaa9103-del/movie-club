# Movie Club Hub 🎬🍿

A collaborative web application designed for film enthusiasts to log movies, curate personal watchlists, and sync up with friends. Create groups, track shared favorites, and vote on your next watch party movie seamlessly.

## ✨ Features

* **Personal Movie Logging:** Track what you've watched, rate titles, and leave reviews.
* **Smart Watchlists:** Maintain a personal queue of movies you want to check out.
* **Friend Groups:** Form custom movie clubs with your friends.
* **Shared Group Watchlists:** Collaborative lists where everyone in the group can add movies.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, HTML5, CSS
* **Icons:** FontAwesome
* **Version Control:** Git & GitHub
